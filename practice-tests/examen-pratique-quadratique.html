Problème 1

Action A : zéros 25,5 et 34,5 → sommet à x = 30. Max = −4(4,5)(−4,5) = 81. Forme canonique : yA = −4(x − 30)² + 81.

36 % × 81 = 29,16. −4(x − 30)² + 81 ≥ 29,16 → (x − 30)² ≤ 12,96 → |x − 30| ≤ 3,6 → x ∈ [26,4 ; 33,6].

Action B : h = −192 / (2·−3) = 32, max = yB(32) = 120. Forme canonique : yB = −3(x − 32)² + 120.

90 % × 120 = 108. −3(x − 32)² + 120 ≤ 108 → (x − 32)² ≥ 4 → x ≤ 30 ou x ≥ 34.

Intersection : [26,4 ; 33,6] ∩ (x ≤ 30 ou x ≥ 34) = [26,4 ; 30]. Durée : 3,6 jours

Problème 3

Rayon : 4w² − 12w + 9 = (2w − 3)² → r = 2w − 3. Carré : côté = 2w + 1. Rectangle : (2w + 1)(3w + 2), donc mQC = 2w + 1 et mCE = 3w + 2.

Pythagore dans le triangle CED : (2w + 1)² + (3w + 2)² = 277 → 13w² + 16w − 272 = 0. Δ = 14 400 → w = 4 (on rejette w = −136/13).

Côté du carré = 9, CE = 14, rayon = 5. C(9, 0), Q(9, 9), S(9, 14), E(23, 0).
